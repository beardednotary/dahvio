Navy PRT Score Chart 2026

The Navy Physical Readiness Test scores three events — push-ups, the forearm plank, and a cardio event — each on a 0–100 point scale. This page lists the maximum (100-point) and minimum passing (60-point) marks for every age group and gender under OPNAVINST 6110.1L Table 4-1 (sites below 5,000 ft), plus how the overall performance categories work. To score an exact number for any performance in between, use the Navy PRT calculator.

Overall Categories

How the overall score is graded

Your three event scores are averaged. The average maps to a performance category:

CategoryAverage score
Outstanding90 – 100
Excellent75 – 89
Good60 – 74
Satisfactory45 – 59
FailureBelow 45, or any single event failed

A failure in any one event fails the whole PRT no matter how high the average. High-year-tenure and other program rules can require a higher category — check the current PFA cycle guidance with your command fitness leader.

Between The Lines

Scoring a number between the max and the minimum

The tables above are just the two endpoints of each scale. Every rep, second, and split in between has its own point value, and the three events are then averaged. Working that out by hand from the full OPNAVINST 6110.1L tables is slow, especially if you want to test a "what if" before test day.

FAQ

Common questions

What is a passing Navy PRT score?

Each event is scored 0–100 and the three are averaged. An average of 60+ is Good; the minimum passing category under OPNAVINST 6110.1L is Satisfactory. A failure in any single event fails the PRT regardless of the average.

What events are on the 2026 Navy PRT?

Push-ups (2 minutes), the forearm plank (max hold), and a cardio event. The 1.5-mile run is primary; approved alternates are the 2 km row, 500-yard swim, and 450-meter swim.

Does altitude change the run standard?

Yes. Table 4-1 covers sites below 5,000 ft. Table 4-2 applies at 5,000 ft and above and allows more time on the run and row for the same score.

What are the Navy PRT age groups?

17-19, 20-24, 25-29, 30-34, 35-39, 40-44, 45-49, 50-54, 55-59, 60-64, and 65+. Standards ease with each older group.
