How It Works

One number, one response page

Every UN number maps to exactly one ERG guide number — a two- or three-digit reference to a standardized page in the Emergency Response Guidebook covering potential hazards, public safety distances, and initial response actions for that material or material family. This tool matches your UN number or material name against a database of common entries and returns that guide number directly, so you don't have to flip through the index first.

This tool returns the guide number only, not the full guide page content. Pair it with your current official ERG for the complete hazards, isolation distances, and response steps — or see the UN Number Lookup tool for the full browsable table.

FAQ

Common questions

What is an ERG guide number?

A two- or three-digit page reference in the Emergency Response Guidebook covering potential hazards, safety distances, and initial response steps for a material or material family. Every UN number maps to one.

How do I find the ERG guide number for a UN number or material?

Type the UN number or material name above. It's matched against 100+ commonly shipped materials and returns the guide number, class, and packing group.

Does this replace the physical ERG guidebook?

No. It returns the guide number only, not the full guide page content. Always consult the current official ERG for complete response guidance.

What if my material isn't in this tool?

This covers 100+ of the most common materials as a free reference. HazMat Pro's Identify feature also handles free-text and descriptive queries offline.
