OPNAVINST 6110.1L, explained

OPNAVINST 6110.1L is the instruction behind the Navy Physical Fitness Assessment (PFA). It's the "L" revision of the Physical Readiness Program instruction, and it defines the two halves of the PFA — the Body Composition Assessment and the Physical Readiness Test — along with every scoring table and rule. This page summarizes what it covers.

Structure

PFA = BCA + PRT

Body Composition Assessment

Height and weight first. Sailors within standards pass outright. Those over the weight-for-height screen get a single-site abdominal circumference measurement against the maximum for their sex.

Physical Readiness Test

Three scored events — push-ups, forearm plank, and a cardio event — each 0–100 points, averaged into an overall score and category.

A Sailor must pass both parts. A BCA failure or a PRT failure is a PFA failure.

The PRT Events

What you're scored on

  • Push-ups — two minutes, to a standard form. Curl-ups were removed under the 6110.1 series.
  • Forearm plank — a single max-effort hold, now the permanent core event.
  • Cardio — the 1.5-mile run is primary. Approved alternates: the 2 km row on a Concept2 erg, the 500-yard swim, and the 450-meter swim. Each has its own table.

Eleven age groups run from 17–19 through 65+. Standards ease with each older group and differ by sex.

Scoring

Categories and the passing line

CategoryAverage score
Outstanding90 – 100

FailureBelow 45, or any single event failed

A failure in any one event fails the PRT regardless of the average. See the full Navy PRT score chart for the per-event numbers.

Details Worth Knowing

Other rules in the instruction

Altitude tables

Table 4-1 covers sites below 5,000 ft. Table 4-2 gives more time on the run and row at 5,000 ft and above.

One PFA per year

At least one official assessment each calendar year; each cycle's windows come from the current PFA NAVADMIN.

Failure consequences

Multiple PFA failures within a rolling window trigger administrative separation processing.

PRIMS-2

Results are recorded in the Physical Readiness Information Management System.

FAQ

Common questions

What is OPNAVINST 6110.1L?

The OPNAV instruction governing the Navy Physical Readiness Program — it defines the PFA (BCA + PRT), the scoring tables, and the rules.

What's the difference between the PFA and the PRT?

The PFA is the whole assessment. The PRT is just the three scored fitness events; the BCA is the body composition check.

What events are in the PRT?

Push-ups, the forearm plank, and a cardio event (1.5-mile run, or the 2 km row / 500-yard swim / 450-meter swim alternates).

How many PFAs per year?

At least one official PFA per calendar year, with cycle details set by the current PFA NAVADMIN.
